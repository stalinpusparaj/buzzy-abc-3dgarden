## Log

- **2026-10-13 · Repo layout.** The game lives at the root of `github.com/stalinpusparaj/buzzy-abc-3dgarden` (moved there on 2026-10-14 at the owner's request; it was briefly pushed to `PILGRIM` by mistake); both briefs are copied to `docs/`. *Why:* CI and static deploys expect `package.json` at the repo root. *Rejected:* making the whole `PILGRIM/` folder the repo with the game in a subfolder.
- **2026-10-13 · Relative `base: './'`.** One `dist/` works at `/`, `/play/` or any subpath without a rebuild; `BASE_PATH=/play/ npm run build` pins an absolute base if a host needs it. E2E serves the build under `/play/` to prove it. *Rejected:* hard-coding `/play/`.
- **2026-10-13 · Dev tools behind a `__DEV_TOOLS__` compile-time flag.** True in `vite` dev and `--mode qa` builds, false in production, so `src/dev/**` is tree-shaken out. `check-budgets.ts` greps `dist/` for a marker string to prove it. A QA build (`npm run build:qa`) keeps the perf overlay for real-device testing. *Rejected:* `import.meta.env.DEV` only (would make on-device perf checks impossible).
- **2026-10-13 · Stricter TS flags.** `noUncheckedIndexedAccess`, `noUnusedLocals/Parameters`, `noImplicitOverride` on top of `strict`. `exactOptionalPropertyTypes` was tried and dropped: it fights three.js's own typings more than it catches bugs.
- **2026-10-13 · Scope-based tweens.** `src/core/tween.ts` ties every tween, timer and per-frame callback to a `Scope`. Killing a scene's scope drops its pending promises, so `async` sequences stop cleanly instead of animating disposed objects. *Rejected:* a global tween list with cancel-by-id.
- **2026-10-13 · QA fps probe uses headless Chromium on Metal** (`scripts/probe.ts`, `--use-angle=metal`). The default headless GPU is SwiftShader (CPU) which would make fps numbers meaningless.
- **2026-10-13 · Git workflow.** Phase 0 is the initial commit on `main`; later phases land on the `mvp` branch, pushed after each phase, then go to `main` through one PR.
- **2026-10-13 · 3D glyphs: outline JSON + runtime extrusion.** `build-letters.ts` writes compact outlines (`src/data/glyphs.{lang}.json`, ~4 KB per language); the game extrudes them with a 3-segment bevel and caches the geometry. *Rejected:* one GLB per glyph (more files, needs gltf-transform at build time for no visual gain).
- **2026-10-13 · Every Tamil uyir glyph is one code point.** அ ஆ இ ஈ உ ஊ are U+0B85–U+0B8A, each with its own glyph in Baloo Thambi 2 (glyph #9–#14); no shaping engine needed. `build-letters.ts` fails the build if any future glyph needs more than one code point or is missing from the font.
- **2026-10-13 · Fonts are subset by script, not to single glyphs.** Fontsource's Latin and Tamil woff2 subsets are shipped as-is: the parent zone needs full readable text in both languages, so subsetting to the 12 lesson glyphs would break it. *Rejected:* `subset-font` (harfbuzz WASM dev dependency) for ~10 KB savings.
- **2026-10-13 · Stroke box.** Stroke files use a square box centred on the glyph's bounds with 5 % padding (`src/core/glyphBox.ts`); the stroke editor, the trace plot and the 3D glyphs all share it, so authored strokes line up with any font. English strokes were measured from Baloo 2 with scanlines (centre lines of each stem/bowl).
- **2026-10-13 · Mini-game templates are lazy chunks.** `registry.ts` maps template ids to `import()` factories; the template-id list lives there too, so the zod schema and the `TemplateId` type both derive from it. Adding a 4th template = one id + one factory.
- **2026-10-13 · Mini-game "stage".** Each template plays on a local frame floating just in front of and above its bud, with the camera 10.5 units away. Nothing in the garden can sit between camera and stage, and the bud/garden stay visible behind it.
- **2026-10-13 · Placeholder audio is synthesised.** `scripts/make-placeholder-audio.ts` builds the SFX sprite, a 100 bpm loop and a dummy song from oscillators and Karplus-Strong plucks (no samples, no third-party material), encoded to MP3 with ffmpeg. `src/data/audio.json` points at the files, so real audio replaces them without code changes. `cues.en.json` matches the dummy song's bells and must be re-recorded with the Cue Recorder for the real song.
- **2026-10-13 · VO lookup order.** `{letterId}_{id}` recording → shared `{id}` recording → speechSynthesis (en-IN / ta-IN, rate 0.85). Lines containing `{glyph}`/`{word}` should be recorded per letter (`A_pp_instruction.mp3`) and added to the manifest under that id, per ASSET_PROMPTS §2 ("no stitched VO"). TTS is disabled under `?e2e=1` so tests are deterministic.
- **2026-10-13 · VO id `thats_a` added** for Basket Match's "That's a fish!" (brief §5.4). Its Tamil text is a placeholder (just the word) and is marked `TODO(content)` + `REVIEW(ta)`.
- **2026-10-13 · `LetterDef.vo.intro` = the template instruction id** (`pp_instruction` / `tt_instruction` / `bm_instruction`), so one letter can override its instruction line later without code changes.
- **2026-10-13 · Tamil Basket Match distractors.** இ (leaf) uses squirrel + swing; ஊ (swing) uses leaf + goat. Each pair deliberately avoids the near-identical vowel (இ/ஈ, உ/ஊ) so a 4-year-old isn't asked to tell i from ī by ear. All Tamil content is marked `REVIEW(ta)`.
- **2026-10-13 · Tamil placeholder strokes come from the glyph skeleton.** A throwaway tool rasterised each glyph, thinned it (Zhang-Suen), traced the branches and chained smooth continuations. The result is 2–6 strokes per letter, centred on the letterform but in no particular *order*. Files carry `"placeholder": true`; the owner will author real stroke orders in the Stroke Editor (brief §5.3). The dots of ஈ aren't traced.
- **2026-10-13 · Both fonts load at boot** (~40 KB total) because the HUD language button shows A and அ at all times. *Rejected:* loading Tamil on first toggle (the button would flash a fallback glyph).
- **2026-10-13 · Glyph screenshot tests are macOS-only.** Baselines (`tests/e2e/tamil.spec.ts-snapshots/`) were recorded on Metal and checked by eye; pixel output differs across GPUs, so CI on Linux skips them rather than flaking.
- **2026-10-13 · No-Tamil-voice fallback.** If the device has no ta-IN speechSynthesis voice, every visible glyph (3D letters and bubbles, named `glyph-*`) squashes and a chime plays (brief §6.4).
- **2026-10-14 · Tracing follows each stroke from its start to its end (owner report: "Tamil tracing is wrong").** Three fixes:
  1. *Direction-strict engine* (`traceMath.ts`, "grip" model). A touch takes hold only at Buzzy's place on the trail (before a stroke starts, that is the green start ball). The hold then slides forward within a local look-ahead of `max(tol/2, min(15 % of the stroke, 1.5 × tol))`. Before this, the look-ahead was 15 % of the stroke length (0.26–0.41 box units on the long Tamil strokes), so tracing backwards or the wrong way round a starting loop still earned 17–28 % of the trail. It now earns 0 % on every English and Tamil stroke (unit tests over every stroke file, plus `tests/e2e/traceDirection.spec.ts`).
  2. *A stroke ends at its end.* A stroke completes at ≥ 85 % coverage (brief §5.3) **and** with the finger on the end star (`END_REACH` = 0.05, never more than one tolerance). On long Tamil strokes the last 15 % is a whole bar or curl, which used to chime early.
  3. *Visible direction.* The current stroke shows a green start ball with an arrow, white chevrons pointing along the path, and a red star at the end. A "follow-me" sparkle runs start → end when each stroke begins and on every hint, and later strokes are dimmed. Buzzy now hovers beside the progress point instead of sitting on the start dot (brief §5.3), because she hid the only direction cue.
- **2026-10-14 · Tamil stroke order sources.** Order and direction were reconciled from the Wikimedia Commons stroke animations (Wikiversity "Tamil Writing Vowels", CC BY-SA 3.0), the UT Austin Tamil Script Learners Manual, the Twinkl India vowel tracing card/worksheet, and the Saja Tuition, Kutties Corner and Arumbugal videos, then mapped onto the Baloo Thambi 2 letterform. A pen retrace in the animations (e.g. up the stem of அ, then down it) is modelled as a lift, because a tracing path can't double back over its own ink. **Still to confirm with a Tamil Nadu teacher:** the direction of ஈ's left leg (sources disagree; the data has it bottom-to-top). Only ஆ and உ use Trace the Trail in normal play (brief §6.3); the other four stroke files are used only if their template changes.
- **2026-10-14 · All six Tamil letters use Trace the Trail** (owner request), replacing the brief §6.3 mix of Pollen Pop / Basket Match for அ இ ஈ ஊ. Their distractor lists are kept in the data so switching back is a one-field change.
