# Buzzy ABC Garden

A browser-based 3D letter garden for children aged 3–6, in English and Tamil. Brief: [docs/BUILD_PROMPT.md](docs/BUILD_PROMPT.md).

## Run

```bash
npm install
npm run dev            # http://localhost:5173  (add ?dev=perf for the perf overlay)
npm test               # unit tests
npm run e2e            # builds, serves under /play/, runs Playwright
npm run build && npm run budgets
```
